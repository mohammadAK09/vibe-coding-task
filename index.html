Describe what you're teaching and who it's for. An n8n workflow asks an AI model for four objectives that climb Bloom's taxonomy and three questions to check understanding, then logs the result to Google Sheets.

      How it works

      1. This website sends your topic, audience and level to an n8n webhook.
      2. n8n passes them to an AI model (Google Gemini) with an instructional design prompt.
      3. n8n checks the AI's answer and appends a row to a Google Sheets log.
      4. n8n replies to the website, which draws the staircase and the quiz.
      Built with HTML, CSS and JavaScript, n8n, GitHub Pages and GitHub Actions.
